# Proyecto Tienda de Videojuegos / Project Videogame Store

**Render URL**: https://proyecto-tienda-videojuegos-jy4a.onrender.com/swagger/

API desarrollada usando **.NET 8, EF Core y PostgreSQL**
Desplegada en render con Docker para su uso y prueba

Para clonar el repositorio solo ejecute el siguiente comando en la carpeta en la que desee
clonarlo:
`git clone https://github.com/DanielGS11/Proyecto_Tienda_Videojuegos/`
